# Personal website

v1 - simplest jekyll

v2 - minimal mistakes cleaner appearance

v3 - hand-written static HTML/CSS, no framework

## Develop

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

No build step. Edit `index.html` and refresh. Pushing to `master` deploys via GitHub Pages (`.nojekyll` serves files as-is).
